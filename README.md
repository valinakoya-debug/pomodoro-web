# 番茄钟 🍅（网页版）

轻量 PWA 番茄钟：25 分钟专注 + 5 分钟短休息，每 4 轮一次长休息，节奏可调。

- 单文件 `index.html`，无框架、无构建步骤
- 支持 PWA：加入主屏幕后独立全屏运行，图标复用桌面版
- 计时基于真实时间戳，页面被挂起后重开会自动追平进度
- 提示音由 Web Audio 实时合成，无音频文件
- 数据存于浏览器 localStorage

## iPhone 安装

1. Safari 打开本页面
2. 分享按钮 → **添加到主屏幕**

## 本地开发

在 `web/` 目录运行任意静态服务器，例如：

```bash
python3 -m http.server 8080
```

## 说明

- 锁屏期间 iOS 会挂起页面，重新打开时自动按真实时间追平；如需锁屏准点通知，需接入 Web Push 服务端
